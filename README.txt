PWA ASSET MANAGEMENT

1. Ekstrak seluruh file ZIP.
2. Upload semua file ke GitHub Pages atau hosting HTTPS dalam folder yang sama.
3. Buka index.html melalui alamat HTTPS di Chrome/Edge.
4. Pilih Instal aplikasi atau Tambahkan ke layar utama.
5. Buka sekali saat online agar cache offline tersimpan.

Catatan: service worker tidak berjalan melalui file://.
